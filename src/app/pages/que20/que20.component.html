Question 20: Route Guard Protected Admin Page

Status: {{ authService.isLoggedIn() ? 'Logged In (Admin)' : 'Logged Out (Guest)' }}

This demonstrates a route guard (canActivate: [authGuard]) that prevents unauthorized users from accessing the /admin page unless they are logged in.

Authentication Control

Current State: {{ authService.isLoggedIn() ? 'Authenticated as Admin' : 'Not Authenticated' }}

How to test:
  1. While Logged Out, click "Go to /admin Page" or enter /admin in the browser URL. The guard will block access and show an alert.
  2. Click "Log In as Admin", then click "Go to /admin Page". The guard will allow you to view the Admin Dashboard!
